# ZylexStore Authentication Backend

A complete authentication backend system for ZylexStore e-commerce platform with OTP verification.

## Features

- ✅ User registration with email verification via OTP
- ✅ Secure login with JWT authentication
- ✅ OTP-based email verification (6-digit codes)
- ✅ Password reset functionality
- ✅ Role-based access control (User/Admin)
- ✅ Rate limiting for API protection
- ✅ Comprehensive logging with Winston
- ✅ Email templates for OTP delivery
- ✅ MongoDB integration with Mongoose
- ✅ Input validation with Joi
- ✅ Security headers with Helmet
- ✅ CORS configuration
- ✅ Health check endpoint

## Prerequisites

- Node.js 14.x or higher
- MongoDB 4.x or higher
- npm or yarn
